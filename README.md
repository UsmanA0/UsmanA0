## Избранные проекты

**[QuickChat](https://github.com/UsmanA0/QuickChat-Backend)** · мессенджер для десктопа  
Клиент на PyQt6 отправляет сообщения через Django REST Framework и получает их по WebSocket через Centrifugo. При открытии чата можно загрузить до 3000 последних сообщений.

**[drf-social-network](https://github.com/UsmanA0/drf-social-network)** · API социальной сети  
Пользователи публикуют посты, оставляют комментарии и ставят лайки. Редактировать запись может только её автор. Просмотры каждой публикации считаю в Redis.

**[DjangoStripe](https://github.com/UsmanA0/DjangoStripe)** · оплата заказов  
Сервис на Django REST Framework собирает несколько товаров в заказ и создаёт для него одну платёжную сессию в Stripe Checkout.
